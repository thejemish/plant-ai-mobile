# Screenshot Checklist

Capture these screens for the Phase 7 submission packet after installing a preview build on a Pixel-class Android device.

1. Onboarding welcome and model setup with **Skip & try demo** visible.
2. Scan tab with camera controls and demo scan options.
3. Demo scan result showing confidence, Gemma panel, evidence, symptoms, and citations.
4. Treatment plan with method tabs, checklist state, weather advisory, and outcome controls.
5. Advisor Ask with a cited offline answer.
6. Advisor Library document detail with bookmarked state.
7. Pest guide list and pest detail.
8. Crop calendar with a scheduled reminder.
9. Home with weather advisory and recent scan.
10. Me About with model and architecture contract details.

Recommended dimensions:

- Android Pixel portrait: 1080 × 2400
- Crop only the device frame if the app content remains fully visible.
- Avoid screenshots while sync, model download, or notification permission sheets obscure the primary UI.
